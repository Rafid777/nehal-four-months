# Nehal — Four Months of Magic 💙

A celebratory website celebrating our little prince **Nehal's 4-month milestone**! 👶✨

## 🌐 Live Website
Visit the live page at: **[https://rafid777.github.io/nehal-four-months/](https://rafid777.github.io/nehal-four-months/)**

## ✨ Features
- **Hero Section**: Featured polaroid photo frame of Nehal with gentle floating cloud and starry decorations.
- **Memory Lane**: Curated photo memory cards celebrating Nehal's sweetest moments and milestones.
- **Interactive Surprise**: Tap-to-open gift box with celebratory confetti animation and heartfelt wishes.
- **Special Letter**: Dedicated letter section filled with love and prayers.
- **Local Photo Upload Preview**: Easily upload additional photos in the browser to preview them instantly in the gallery.
- **Responsive Design**: Polished layout tailored for mobile phones, tablets, and desktop displays.
